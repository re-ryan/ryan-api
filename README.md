# ryan-api

Projeto acadêmico Biblioteca Fácil, desenvolvido em Java 21 com Spring Boot e Maven.

## Contexto

Biblioteca Fácil é uma plataforma para descoberta de livros físicos em bibliotecas parceiras e solicitação de reserva para retirada presencial.

O sistema não substitui os sistemas internos das bibliotecas. Ele atua como uma camada de catálogo, descoberta, disponibilidade e solicitação de reserva.
